# TGFocus for Windows v0.1.1

Предварительный выпуск для **Windows 11 x64** с исправлениями после code review. Автоматические проверки выполнены; ручная проверка именно этой новой сборки ещё не завершена, поэтому она не объявляется стабильной.

## Исправления

- После обрыва сети и исчерпания попыток Telegram-библиотеки приложение само восстанавливает соединение. Повторные попытки используют растущую паузу до минуты и соблюдают дополнительное ожидание от Telegram. Запуск до появления Wi-Fi/VPN также восстанавливается автоматически.
- «Переподключить» доступно во время ожидания. Сохранённые API ID / API Hash повторно вводить не нужно; отозванная сессия явно требует нового входа. Выход из аккаунта и ручное переподключение отменяют восстановление старого соединения.
- Повреждённый `rules.json` защищён от перезаписи, в том числе при подключении и предложении автозагрузки. Приложение объясняет, как восстановить настройки; временные изменения применяются без уничтожения исходного файла.
- Сообщения из одного чата разделяют один запрос настроек mute. Количество запросов и ожидающих чатов ограничено; устаревшие ответы после изменения настроек не используются. Если mute проверить не удалось, уведомление не проходит.
- Кэш метаданных Telegram ограничен 4096 записями и обновляет запись собеседника по ID. Старые имена и данные больше не копятся бесконечно, в том числе при выключенном фильтре. Формат сохранённой сессии не меняется.

Локальные правила, добровольный ИИ через OpenRouter/DeepSeek, исключения ИИ, уведомления, WNF и автозагрузка с согласия пользователя сохранены. Подробности: [Windows-инструкция](https://github.com/MXLev/tgfocus/blob/windows-v0.1.1/WINDOWS.ru.md).

## Скачать и обновить

Скачай `TGFocus-Windows-v0.1.1-x64.zip` и соседний `.sha256`. Заверши прежний TGFocus через трей, полностью распакуй новую папку в постоянное место и запусти `TGFocus.exe`. Не отделяй EXE от `_internal` и `helper`. Если включена автозагрузка, обнови путь к новой копии в «Обзоре».

Настройки и учётные данные остаются в `%LOCALAPPDATA%\TGFocus`. Если приложение сообщает об ошибке чтения `rules.json`, заверши его, сохрани копию файла и восстанови JSON либо переименуй повреждённый файл. После запуска без `rules.json` создаются начальные правила с выключенным фильтром. Данные DPAPI не удаляй. Архив v0.1.0 не заменялся.

## Проверка и ограничения

Регрессионные тесты проверяют потерю сети, отозванную сессию, смену аккаунта во время восстановления, выход, защиту настроек, параллельные mute-запросы и ограничение кэша. Windows CI дополнительно проверяет собранный worker и GUI, DPAPI, WNF, ярлык автозагрузки во временной папке, иконки и версии обоих EXE. Архив и распакованные файлы проверяются Defender с обновлением баз; отчёт, SHA-256 и сведения об исходном коммите прилагаются.

Пакет **не подписан доверенным сертификатом издателя**. SignPath ещё не подключён. Успешные тесты и сканирование не гарантируют отсутствие предупреждений Chrome Safe Browsing / SmartScreen и не заменяют проверку настоящих уведомлений на компьютере пользователя. WNF — недокументированный механизм Windows, совместимость может измениться.

ИИ по умолчанию выключен; его включение отправляет подходящий текст внешнему провайдеру на его условиях. См. [приватность](https://github.com/MXLev/tgfocus/blob/windows-v0.1.1/PRIVACY.md), [системные изменения и удаление](https://github.com/MXLev/tgfocus/blob/windows-v0.1.1/WINDOWS-UNINSTALL.ru.md), [политику подписи](https://github.com/MXLev/tgfocus/blob/windows-v0.1.1/CODE_SIGNING_POLICY.md).
