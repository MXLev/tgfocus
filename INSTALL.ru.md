# Установка Telegram Focus

Нужен Mac с Apple Silicon (M1 или новее) и macOS 14 или новее.

При обновлении сначала заверши уже запущенный Telegram Focus через значок самолётика → «Завершить Telegram Focus». Закрытие окна настроек не останавливает приложение. Сессия и правила хранятся отдельно от `.app`; удалять их для обновления не нужно.

1. Откройте TGFocus-unsigned-arm64.dmg.
2. Перетащите Telegram Focus в Applications (Программы).
3. Извлеките образ диска и откройте Telegram Focus из Программ.
4. Если macOS блокирует запуск, откройте «Системные настройки → Конфиденциальность и безопасность», найдите сообщение об этом приложении и нажмите «Всё равно открыть». Подтвердите запуск. Делайте это только для сборки, которую вы намеренно скачали из MXLev/tgfocus.
5. Нажмите значок самолётика в строке меню → «Открыть настройки…» и подключите Telegram с собственными API ID и API Hash с https://my.telegram.org/apps.

Эта сборка не подписана сертификатом Apple Developer ID и не прошла нотариальное заверение Apple. Она использует локальную ad-hoc подпись, поэтому macOS может предупредить о непроверенном разработчике. Отключать Gatekeeper не нужно.

Python и зависимости включены в приложение. Устанавливать Python или Xcode для запуска DMG-сборки не требуется.

В бесплатной сборке с локальной ad-hoc подписью доступен **ручной фильтр**. Авто-режим недоступен: эта подпись не предоставляет системное право на неотложные уведомления. В «Обзоре» нажми «Перейти в ручной режим» и подтверди предупреждение; сохранённая настройка авто-режима до подтверждения оставляет доставку на паузе.

В **Системные настройки → Фокусирование → выбранный режим → Приложения → Разрешить уведомления от** добавь **Telegram Focus**, а обычный Telegram оставь вне списка. Если у Telegram включён обход через неотложные уведомления, отключи его. Включай фильтр TGFocus вручную вместе с фокусированием, а перед выключением фокусирования выключай фильтр. Иначе возможны двойные уведомления от TGFocus и Telegram. Заглушённые в Telegram чаты и темы форумов остаются тихими.
