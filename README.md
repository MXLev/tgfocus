# TGFocus

**Telegram остаётся рядом. Шум — за пределами внимания.**

TGFocus показывает уведомления о важных сообщениях Telegram: от выбранных людей, по срочным словам, упоминаниям и ответам. Работает в фоне рядом с часами, пока обычный Telegram можно оставить без звука.

Бесплатное приложение с открытым кодом для Windows и macOS. Локальные правила работают без нейросетей; в Windows можно дополнительно подключить ИИ для оценки важности.

## Что умеет

- Пропускает сообщения от важных людей и сообщения с заданными словами и фразами.
- Фильтрует группы и каналы, с отдельными исключениями для нужных чатов.
- Отдельно разрешает упоминания и ответы на свои сообщения.
- Соблюдает mute-настройки Telegram, включая темы форумов: заглушённые чаты остаются тихими даже при совпадении с правилами.
- Подключается через QR-код или код входа с поддержкой двухэтапного пароля.
- Позволяет проверить локальные правила на примерах без входа в Telegram.
- Показывает короткий журнал решений без текста переписки. Закрытие окна настроек оставляет приложение работающим.

В **Windows v0.1.0** также доступны:

- **ИИ-фильтр через OpenRouter или DeepSeek**: свой ключ, модель, порог важности и исключения чатов из внешней обработки. При сбое используются локальные правила и показывается беззвучное сообщение о проблеме.
- **Авто-режим по «Не беспокоить»**: TGFocus разрешает доставку, когда системный режим включён. Используется недокументированный WNF; после обновлений Windows совместимость может измениться. Ручное управление доступно всегда.
- **Автозагрузка с согласия пользователя** и запуск в трее без открытия настроек.

В опубликованной **macOS v1.4.0** переключение ручное, ИИ отсутствует. ИИ и автоматизация через Apple «Команды» подготовлены в исходниках для следующего macOS-выпуска; скачанный DMG v1.4.0 их не содержит.

## Первый запуск на Windows

1. Распакуй всю папку в постоянное место, например `%LOCALAPPDATA%\Programs\TGFocus`, и запусти `TGFocus.exe`. Значок появится в трее, иногда под стрелкой **`^`**.
2. Получи собственные **API ID** и **API Hash** на [my.telegram.org/apps](https://my.telegram.org/apps), введи их во вкладке **«Подключение»**. Для QR-входа открой Telegram на телефоне → **Настройки → Устройства → Подключить устройство**.
3. Выбери важных людей, ключевые слова и исключения для групп. Фильтр на новой установке выключен: включи его в **«Обзоре»**.
4. В **Обзор → Уведомления Windows** отправь тестовое уведомление при выключенном «Не беспокоить». Разреши уведомления и баннеры TGFocus в **Параметры → Система → Уведомления**.
5. Для использования вместе с «Не беспокоить» добавь **TGFocus** в **Задать приоритетные уведомления → Добавить приложения**, оставив обычный Telegram заглушённым. Повтори тест при включённом режиме. Если TGFocus не появился в списке, используй **«Восстановить регистрацию TGFocus»** в приложении и заново открой параметры Windows.
6. По желанию включи автоматизацию и автозагрузку в **«Обзоре»**, а ИИ — в отдельной вкладке, предварительно добавив конфиденциальные чаты в исключения.

Полная инструкция, обновление и диагностика: **[TGFocus для Windows](WINDOWS.ru.md)**. Вкладка **«Как настроить»** также есть в самом приложении.

## Первый запуск на Mac

1. Открой установленное приложение → самолётик в строке меню → **«Открыть настройки…»**.
2. Подключи Telegram со своими API ID и API Hash, выбери людей, слова и исключения.
3. Разреши уведомления TGFocus. В **Системные настройки → Фокусирование → нужный режим → Приложения** разреши **Telegram Focus**, оставив обычный Telegram заглушённым.
4. Включай фильтр TGFocus вместе с фокусированием и выключай его перед выходом из режима, чтобы избежать дублей.

Инструкции для опубликованной v1.4.0: [установка](https://github.com/MXLev/tgfocus/blob/v1.4.0/INSTALL.ru.md) · [пошаговая настройка](https://github.com/MXLev/tgfocus/blob/v1.4.0/SETUP.ru.md).

## Приватность и ограничения

По умолчанию правила обрабатываются на твоём компьютере. Проект не использует собственный сервер для переписки и не собирает телеметрию. TGFocus не отправляет сообщения в Telegram, не отмечает их прочитанными и не скачивает вложения.

**ИИ выключен по умолчанию.** При его включении первые 4000 символов подходящего сообщения и заданный контекст передаются OpenRouter / провайдеру модели либо напрямую DeepSeek. Текст может содержать личные данные. Заглушённые в Telegram и исключённые из ИИ чаты не отправляются; исключения используют локальные правила. Ключ API принадлежит пользователю, стоимость и лимиты определяет провайдер. Подробнее: [ИИ-фильтр](AI.ru.md) · [Privacy policy](PRIVACY.md).

Ключи и сессия хранятся в Связке ключей macOS либо защищаются Windows DPAPI для текущего пользователя. Код входа и пароль 2FA не сохраняются. Не присылай ключи, сессию и переписку автору или в issue.

Приложение работает, пока запущено, компьютер не спит и есть соединение с Telegram. Голосовые не расшифровываются; звонки и секретные чаты не поддерживаются. Нейросеть может ошибаться. Если обычный Telegram тоже показывает уведомления, возможны дубли.

## Обновление и удаление

На Windows заверши TGFocus через трей и распакуй новый выпуск в отдельную папку целиком. Настройки остаются в `%LOCALAPPDATA%\TGFocus`. Если включена автозагрузка, запусти новую копию и нажми **«Обновить путь к этой копии TGFocus»**. Инструкция описывает [системные записи, удаление приложения и отдельных пользовательских данных](WINDOWS-UNINSTALL.ru.md).

На Mac заверши приложение и замени его в **Программах** новой версией. Правила хранятся в `~/Library/Application Support/TelegramFocus`, секреты — отдельно в Связке ключей.

Автоматического обновления нет. Новые готовые версии публикуются в **[GitHub Releases](https://github.com/MXLev/tgfocus/releases)**; архивы Actions предназначены для проверки изменений до релиза.
