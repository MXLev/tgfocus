# TGFocus

Локальный фильтр уведомлений Telegram для macOS: важные люди, срочные слова и упоминания проходят, остальной шум остаётся тихим.

Нативный интерфейс на SwiftUI, связь с Telegram через Telethon. Обработка правил выполняется на Mac без внешней нейросети и серверов-посредников. Приложение живёт в строке меню, без значка в Dock.

## Что умеет

- Пропускать любые личные сообщения от выбранных людей.
- Проверять остальные личные сообщения по словам и фразам: например, «срочно», «позвони», «нужна помощь».
- Глушить группы и каналы, оставляя исключения для нужных чатов.
- Независимо включать уведомления об упоминаниях и ответах на свои сообщения в группах.
- Соблюдать выключенные уведомления чатов и общие mute-настройки Telegram.
- Вручную включать фильтр во время фокусирования macOS.
- Входить через QR-код, код подтверждения и пароль двухэтапной аутентификации.
- Показывать реальный способ доставки кода, выбранный сервером Telegram.
- Проверять правила на примерах без входа в аккаунт.
- Показывать короткий журнал решений в памяти, без текста переписки.

## Как это работает

```text
Telegram → локальный клиент → правила → уведомление macOS
```

В бесплатной сборке с локальной ad-hoc подписью доступен **ручной фильтр**. Авто-режим недоступен: эта подпись не предоставляет системное право на неотложные уведомления. В «Обзоре» нажми «Перейти в ручной режим» и подтверди предупреждение; сохранённая настройка авто-режима до подтверждения оставляет доставку на паузе.

В **Системные настройки → Фокусирование → выбранный режим → Приложения → Разрешить уведомления от** добавь **Telegram Focus**, а обычный Telegram оставь вне списка. Если у Telegram включён обход через неотложные уведомления, отключи его. Включай фильтр TGFocus вручную вместе с фокусированием, а перед выключением фокусирования выключай фильтр. Иначе возможны двойные уведомления от TGFocus и Telegram. Заглушённые в Telegram чаты и темы форумов остаются тихими.

## Установка

Выберите готовый DMG или сборку из исходников. Оба варианта требуют **Mac с Apple Silicon и macOS 14+**.

### Вариант 1: готовое приложение (DMG)

Откройте [GitHub Releases](https://github.com/MXLev/tgfocus/releases) и скачайте `TGFocus-unsigned-arm64.dmg`, если сборка уже опубликована. Откройте образ и перетащите **Telegram Focus** в **Applications (Программы)**. Python и Xcode для запуска не нужны.

Сборка не подписана сертификатом Apple Developer ID и не прошла нотариальное заверение Apple; используется локальная ad-hoc подпись. Если macOS блокирует первый запуск, разрешите его через **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**, только если доверяете скачанной сборке. Отключать Gatekeeper не нужно.

Пошаговая инструкция: [INSTALL.ru.md](INSTALL.ru.md). Если в Releases ещё нет DMG, используйте сборку из исходников ниже.

### Вариант 2: клонировать репозиторий и собрать

Нужны **Mac с Apple Silicon, macOS 14+, Python 3.13 и Xcode Command Line Tools**. Для скачивания зависимостей требуется интернет.

```sh
git clone https://github.com/MXLev/tgfocus.git
cd tgfocus
python3.13 source/build.py
```

Сборка создаёт `Telegram Focus.app` в корне проекта. Среда Python и зависимости упакованы внутрь; для запуска готовой сборки отдельный Python не нужен. Сборка локальная, с ad-hoc подписью, без нотариального заверения Apple.

Инструкция по подключению и настройке: [SETUP.ru.md](SETUP.ru.md).

### Подготовка DMG для релиза

Только для машины сборки: установите [Homebrew](https://brew.sh/) и выполните `brew install coreutils`. Упаковщик использует GNU `sync` из coreutils; штатная утилита macOS не поддерживает нужные параметры. Пользователям готового DMG эти инструменты не нужны. При повторной сборке `build.py` обновляет зависимости существующего Python-окружения.

После сборки приложения на Apple Silicon Mac выполните `bash source/package_dmg.sh`. Образ и файл SHA-256 появятся в `dist/`. Окно образа показывает приложение слева, Applications справа и стрелку между ними; для установки перетащите приложение в Applications. Инструкция также включена в образ.

Для проверки до релиза откройте pull request: после успешного **CI → macOS app and DMG** скачайте артефакт **TGFocus-test-DMG** со страницы запуска Actions, распакуйте ZIP и откройте DMG на своём Mac. Python и Xcode для такой проверки не нужны. Подробные шаги: [CONTRIBUTING.md](CONTRIBUTING.md#get-a-test-installer-without-installing-developer-tools).

Workflow **Build macOS DMG** можно запустить вручную во вкладке Actions для получения артефакта. При отправке тега `v*` (например, `v1.3.0`) он соберёт приложение, выполнит Python- и нативные проверки, проверит упакованный модуль и DMG, затем создаст **черновик** GitHub Release с образом и контрольной суммой. Перед публикацией проверьте установку на Mac и опубликуйте черновик. Apple Developer Program для этого варианта не требуется.

## Первый запуск

1. Откройте приложение и нажмите значок самолётика в строке меню → «Открыть настройки…».
2. Получите собственные API ID и API Hash через [my.telegram.org](https://my.telegram.org/apps). Название приложения при регистрации — например, `Personal Focus`, без слова Telegram.
3. Введите ключи и подключитесь. Для QR-входа: Telegram на телефоне → Настройки → Устройства → Подключить устройство.
4. Разрешите уведомления macOS и выберите ручной режим в «Обзоре». Добавьте TGFocus в разрешённые приложения фокусирования, обычный Telegram оставьте заглушённым. Включайте фильтр вместе с фокусированием и выключайте вручную перед выходом из него.
5. Выберите важных людей, слова и исключения для групп.

Код или API-ключи для этого проекта не нужно присылать автору либо публиковать в issue.

## Данные и ограничения

API-ключи и сессия сохраняются в Связке ключей macOS. Код входа и пароль двухэтапной аутентификации не сохраняются. Правила записываются в `~/Library/Application Support/TelegramFocus/rules.json`, журнал решений остаётся в памяти.

Приложение не отправляет сообщения, не отмечает их прочитанными и не скачивает вложения. Текст уведомлений может сохраняться самой macOS в Центре уведомлений; его отображение можно отключить.

Фильтр работает, пока приложение запущено, Mac не спит и есть соединение с Telegram. Голосовые не расшифровываются; звонки и секретные чаты не поддерживаются. Слова ищутся в тексте и подписях к медиа. Используются полные слова и фразы без учёта регистра и различия «ё/е»; нужные формы слов добавляются отдельно. Сообщения старше двух минут после переподключения не вызывают баннеров.

## Проверки

```sh
python3 -m venv .venv
.venv/bin/python -m pip install Telethon==1.45.0
.venv/bin/python -m unittest discover -s source/tests -p 'test_*.py' -v
```

Проверки охватывают правила, настройки mute в Telegram, отдельные переключатели упоминаний и ответов, вход, QR, двухэтапный пароль, ограничения повторных попыток и безопасную замену приложения. Скрипт сборки дополнительно проверяет обмен с упакованным модулем, открытие и повторное открытие окна настроек, блокировку второго экземпляра, миграцию настроек, политику фокусирования и кодирование/распознавание тестового QR-кода средствами macOS.

## Устройство проекта

| Путь | Назначение |
| --- | --- |
| `source/App/` | Интерфейс SwiftUI, уведомления, Связка ключей, обмен с модулем Telegram |

| `source/Helper/rules.py` | Независимый механизм правил |
| `source/tests/` | Проверки правил и интеграции |
