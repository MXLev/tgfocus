# Подпись Apple и фильтры фокусирования

Текущий бесплатный DMG использует ad-hoc подпись. На проверенном Mac с macOS 26 приложение видно в системном списке Focus Filters, но Add неактивна. `linkd` успешно индексирует `Metadata.appintents`, затем сообщает `Failed to generate bundleIdentity` / `Unable to get teamId`. Параметр Bool и протокол FocusConfiguration присутствуют в метаданных.

## Что требуется

- **Ad-hoc подпись** проверяет целостность кода, но не содержит Apple Team ID. Ручные уведомления TGFocus работают; нативная автоматизация в такой сборке отключена.
- **Apple Development** предназначен для разработки. Возможность создать подходящую локальную сборку с бесплатной Personal Team и добавить её Focus Filter пока не проверена. `Sign to Run Locally` само по себе не означает появление Team ID.
- **Developer ID Application** — сертификат для распространения macOS-приложения вне App Store. Для его получения нужна Apple Developer Program, обычно $99 в год или цена в местной валюте: https://developer.apple.com/programs/enroll/ . Нужен именно Application, а не Developer ID Installer.
- **Нотариальное заверение** — отдельная проверка Apple для удобного первого запуска скачанного приложения. Оно не заменяет подпись и Team ID. Отсутствие нотариального заверения само по себе не является ошибкой из полученного лога.

Проверка подписи установленной копии на Mac:

```sh
codesign --verify --deep --strict "/Applications/Telegram Focus.app"
codesign --display --verbose=4 "/Applications/Telegram Focus.app"
```

В ad-hoc сборке `TeamIdentifier` отсутствует или равен `not set`. В корректно подписанной сборке ожидаются настоящий TeamIdentifier и цепочка сертификата Apple. Самостоятельно прописать строку Team ID в Info.plist недостаточно.

## Что ещё предстоит проверить

Наличие Team ID — предварительное условие, а не доказательство работоспособности интеграции. После получения сертификата нужно подготовить отдельную подписанную сборку и проверить на Mac:

1. Успешную регистрацию App Intents без ошибки bundleIdentity.
2. Создание Focus Filter через активную Add.
3. Возобновление доставки при включении режима, остановку при выключении и после перезапуска приложения.
4. Приоритет главного выключателя и отсутствие дублей с обычным Telegram.

CI текущей бесплатной сборки проверяет запуск приложения, ручной режим и явное обнаружение неподдерживаемой подписи. Он **не подтверждает** создание нативного Focus Filter. Автоматическая подпись Developer ID и нотариальное заверение в release workflow пока не настроены; существующий `source/build.py` выпускает ad-hoc сборку.

Сертификат с приватным ключом (`.p12`), его пароль и ключи нотариального заверения нельзя присылать в чат или коммитить. При настройке CI их следует передавать через защищённые GitHub Actions secrets. Сейчас эти данные для разработки и тестов бесплатной сборки не нужны.
