# Авто-режим через приложение Apple «Команды»

Это необязательная альтернатива ручному переключению. Работает с бесплатной ad-hoc сборкой и не требует Xcode, платной Apple Developer Program, регистрации Focus Filter или полного доступа к диску. Требуется один раз создать пользовательскую команду. Её поведение на конкретной версии macOS проверяется на своём Mac; автоматические тесты TGFocus проверяют чтение результата, ошибки и таймаут, а не системное действие Apple.

## Создать команду

1. Открой **«Команды» / Shortcuts** на Mac. Создай новую команду с именем **TGFocus State**.
2. Добавь действие **«Получить текущий режим фокусирования» / Get Current Focus**.
3. Добавь **«Если» / If**. Выбери полученный режим и условие **«имеет любое значение» / has any value**. Названия могут немного отличаться с языком macOS.
4. В первой ветке добавь **«Текст» / Text** со значением `ON`.
5. В ветке **«Иначе» / Otherwise** добавь **«Текст» / Text** со значением `OFF`.
6. После **«Конец если» / End If** добавь **«Остановить и вывести результат» / Stop and Output**. Выбери магическую переменную **«Результат Если» / If Result**. Нужен текст `ON` или `OFF`, не объект режима и не его название.

```text
Get Current Focus
If Current Focus has any value
    Text: ON
Otherwise
    Text: OFF
End If
Stop and Output: If Result
```

Команда только читает состояние. Действие **«Установить фокусирование» / Set Focus** не нужно.

## Проверить и подключить

1. Запусти команду вручную. Подтверди разрешения, если Apple их запросит. При выключенном Focus она должна выводить `OFF`, при включённом — `ON`, после выключения — снова `OFF`.
2. В TGFocus → **Обзор** включи **«Автоматически по Focus через Команды»**. Если назвал команду иначе, введи её точное имя и нажми Enter / «Проверить сейчас».
3. Оставь **главный переключатель фильтра включённым**. Он разрешает работу; фактическая доставка зависит от результата команды. При главном выключателе в положении «выкл.» опрос прекращается.
4. Нажми **«Проверить сейчас»**. При включённом Focus должны появиться активный значок и статус «Focus включён». При выключенном Focus фильтр на паузе.
5. В macOS → **Фокусирование → выбранный режим → Приложения → Разрешить уведомления от** добавь **Telegram Focus**, а обычный Telegram оставь заглушённым. Это требуется отдельно от команды. В системный раздел «Фильтры фокусирования» добавлять TGFocus не нужно.
6. Проверь получение настоящего уведомления. Также проверь запуск TGFocus при уже включённом Focus, пользовательский режим и режим по расписанию.

Терминал не обязателен. Для диагностики можно выполнить:

```sh
shortcuts run 'TGFocus State' --output-path /tmp/tgfocus-shortcut-check.txt
cat /tmp/tgfocus-shortcut-check.txt
```

Не считай пустой вывод результатом `OFF`: нужен один из двух явных ответов.

## Ограничения

- По умолчанию опрос раз в 30 секунд; доступны 15, 30 и 60 секунд. Переключение не мгновенное, выполнение команды ограничено ожиданием 10 секунд. До следующей проверки после выхода из Focus возможны дубли с обычным Telegram. Для немедленной паузы используй главный выключатель.
- Неверный ответ, отсутствие команды, ошибка или таймаут означают **«состояние неизвестно»**, доставка TGFocus приостанавливается. Очереди запросов нет. После сна состояние сбрасывается и проверяется заново.
- Во время ручного режима и при главном выключателе «выкл.» команда не запускается. Во сне опрос приостановлен.
- Любой включённый Focus разрешает доставку, поэтому TGFocus нужно разрешить в каждом режиме, где нужны его баннеры. Это не выбор конкретного режима.
- Команда выполняется с правами пользователя: используй приведённую простую схему, проверь действия перед включением авто-режима.

Ручной режим остаётся доступным: выключи автоматизацию и управляй фильтром как раньше.
