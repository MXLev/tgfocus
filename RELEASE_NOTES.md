Фильтр уведомлений Telegram для **macOS 14+ на Apple Silicon (M1 и новее)**.

### Новое в 1.5.0

- Необязательное переключение доставки по Focus через пользовательскую команду Apple «Команды». Без Developer ID и системного Focus Filter. Ручной режим остаётся по умолчанию.
- При ошибке команды или неизвестном состоянии доставка приостанавливается. Опрос раз в 15/30/60 секунд (по умолчанию 30); до следующей проверки после выхода из Focus возможны дубли с Telegram.
- Необязательный ИИ-фильтр через OpenRouter или DeepSeek вместо ключевых слов: выбор модели, порог важности, контекст и лимит запросов. По умолчанию выключен. Бесплатность модели и лимиты зависят от провайдера; API DeepSeek может быть платным.
- Отдельный список «Никогда не отправлять в ИИ» для личных, групп и каналов. Исключённые чаты используют локальные правила, заглушённые в Telegram не отправляются. Ключи хранятся в Связке ключей.
- При ошибке/лимите ИИ действуют локальные правила. Запрос содержит первые 4000 символов сообщения без добавления имён, ID, истории и вложений; сам текст может содержать личные данные. Ознакомьтесь с условиями внешнего сервиса перед включением.
- Пошаговые инструкции доступны во вкладке «Как настроить»: [Команды](https://github.com/MXLev/tgfocus/blob/main/AUTOMATION.ru.md), [ИИ](https://github.com/MXLev/tgfocus/blob/main/AI.ru.md).

### Установка и проверка

Скачайте **TGFocus-unsigned-arm64.dmg**, перетащите приложение в Applications, извлеките DMG и запустите из Программ. Python и Xcode для запуска не нужны. Сборка с ad-hoc подписью без нотариального заверения; при необходимости разрешите первый запуск через «Конфиденциальность и безопасность → Всё равно открыть». Не отключайте Gatekeeper.

Разрешите Telegram Focus в списке приложений нужного режима Focus, обычный Telegram оставьте заглушённым. Для авто-режима сначала вручную проверьте команду OFF → ON → OFF. Автоматические проверки проверяют протокол и таймаут команды, приватность исключений, лимиты и резервные правила ИИ на подставных ответах. Действие Apple, реальные API-ключи и доставка Telegram требуют отдельной проверки на вашем Mac.
