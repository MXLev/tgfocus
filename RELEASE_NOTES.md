Локальный фильтр уведомлений Telegram для **macOS 14+ на Apple Silicon (M1 и новее)**.

### Скачать и установить

1. Скачайте **TGFocus-unsigned-arm64.dmg** ниже, откройте его и перетащите Telegram Focus в Applications (Программы).
2. Извлеките DMG и запустите приложение из Программ. Управление — через значок самолётика в строке меню.
3. Подключите Telegram с собственными API ID и API Hash: [пошаговая инструкция](https://github.com/MXLev/tgfocus/blob/v1.4.0/SETUP.ru.md).

Python и Xcode для запуска готового приложения не нужны. Сборка с ad-hoc подписью, без Apple Developer ID и нотариального заверения. Если macOS блокирует первый запуск, разрешите его через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», если доверяете скачанному приложению. Отключать Gatekeeper не нужно. SHA-256 приложен отдельным файлом.

### Что изменилось

- Исправлено открытие и повторное открытие настроек. Меню и главный экран используют один переключатель; значок меняется при включении фильтра.
- Уведомления об ответах и упоминаниях включаются независимо. Учитываются настройки mute чатов и отдельных тем форумов, включая General.
- Добавлена защита от запуска второй копии и запуска прямо с DMG; сборка защищена от параллельного обновления и сохраняет прежнее приложение при ошибке.
- При выключенном фильтре пропускается обработка сообщений; ограничены буферы и кэши. Инструкция для первого запуска доступна внутри приложения.

### Управление ручное

**Автоматического переключения по фокусированию в этой версии нет.** Разрешите Telegram Focus в приложениях выбранного режима, обычный Telegram оставьте заглушённым. Включайте фильтр TGFocus вместе с фокусированием и выключайте его вручную перед выходом — иначе возможны двойные уведомления.

На новой установке фильтр выключен. При обновлении с экспериментального авто-режима он также выключается; правила и сессия сохраняются.

Перед публикацией один и тот же DMG проходит установку, проверку подписи, запуск приложения и воркера, открытие/повторное открытие настроек на macOS 15 и 26. Живые уведомления Telegram проверены пользователем в предрелизной сборке; автоматические проверки не входят в личный аккаунт.
