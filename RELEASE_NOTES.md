Фильтр уведомлений Telegram для **macOS 14+ на Apple Silicon (M1 и новее)**.

**Предварительный выпуск v1.5.0.** Автоматические проверки выполнены; ручная проверка именно этой новой сборки ещё не завершена, поэтому она не объявляется стабильной.

### Исправления после code review

- После длительного обрыва сети и при запуске до появления Wi-Fi/VPN соединение восстанавливается автоматически. Повторные попытки используют растущую паузу до минуты и соблюдают дополнительное ожидание от Telegram. Отозванная сессия требует нового входа; выход и смена подключения отменяют восстановление старой сессии.
- Повреждённый `rules.json` больше не перезаписывается начальными настройками после запуска или изменения правил. Приложение сохраняет предупреждение и применяет изменения только до перезапуска.
- Сообщения из одного чата разделяют запрос настроек mute, число параллельных и ожидающих запросов ограничено. Устаревшие ответы не возвращаются в кэш; при неизвестных настройках уведомление не проходит.
- Кэш метаданных Telegram ограничен 4096 записями и заменяет данные по ID, в том числе при выключенном фильтре. Формат сохранённой сессии остаётся прежним.

### Новое в 1.5.0

- Необязательное переключение доставки по Focus через пользовательскую команду Apple «Команды». Без Developer ID и системного Focus Filter. Ручной режим остаётся по умолчанию.
- При ошибке команды или неизвестном состоянии доставка приостанавливается. Опрос раз в 15/30/60 секунд (по умолчанию 30); до следующей проверки после выхода из Focus возможны дубли с Telegram.
- Необязательный ИИ-фильтр через OpenRouter или DeepSeek вместо ключевых слов: выбор модели, порог важности, контекст и лимит запросов. По умолчанию выключен. Бесплатность модели и лимиты зависят от провайдера; API DeepSeek может быть платным.
- Отдельный список «Никогда не отправлять в ИИ» для личных, групп и каналов. Исключённые чаты используют локальные правила, заглушённые в Telegram не отправляются. Ключи хранятся в Связке ключей.
- При ошибке/лимите ИИ действуют локальные правила. Запрос содержит первые 4000 символов сообщения без добавления имён, ID, истории и вложений; сам текст может содержать личные данные. Ознакомьтесь с условиями внешнего сервиса перед включением.
- При сбое ИИ появляется беззвучное уведомление с переходом к настройкам. Повторы одного сбоя подавляются; при нестабильном подключении — не чаще раза в пять минут.
- Пошаговые инструкции доступны во вкладке «Как настроить»: [Команды](https://github.com/MXLev/tgfocus/blob/v1.5.0/AUTOMATION.ru.md), [ИИ](https://github.com/MXLev/tgfocus/blob/v1.5.0/AI.ru.md).

### Установка и проверка

Скачайте **TGFocus-unsigned-arm64.dmg**, перетащите приложение в Applications, извлеките DMG и запустите из Программ. Python и Xcode для запуска не нужны. Сборка с ad-hoc подписью без нотариального заверения; при необходимости разрешите первый запуск через «Конфиденциальность и безопасность → Всё равно открыть». Не отключайте Gatekeeper.

Перед обновлением завершите старую копию через строку меню. Правила в `~/Library/Application Support/TelegramFocus` и ключи в Связке ключей сохраняются. Если TGFocus сообщает об ошибке чтения `rules.json`, завершите приложение, сохраните копию файла и восстановите JSON либо переименуйте повреждённый файл. После запуска без `rules.json` создаются начальные правила с выключенным фильтром. Удалять сессию и ключи не нужно. Предыдущий DMG v1.4.0 остаётся неизменным.

CI собирает приложение на macOS 15, запускает Python- и Swift-тесты и проверяет запуск из установленного DMG на macOS 15 и 26. Регрессионные проверки покрывают восстановление соединения, выход/смену аккаунта, защиту настроек, параллельные mute-запросы и ограничение кэша. SHA-256 DMG прилагается.

Разрешите Telegram Focus в списке приложений нужного режима Focus, обычный Telegram оставьте заглушённым. Для авто-режима сначала вручную проверьте команду OFF → ON → OFF. Автоматические проверки проверяют протокол и таймаут команды, приватность исключений, лимиты и резервные правила ИИ на подставных ответах. Действие Apple, реальные API-ключи и доставка Telegram требуют отдельной проверки на вашем Mac.
