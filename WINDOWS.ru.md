# TGFocus для Windows — экспериментальный прототип

Небольшое фоновое приложение в системном трее рядом с часами. Окно настроек можно закрыть: приложение продолжает работать. Полный выход — через значок TGFocus → **«Выход»**. Значок может находиться под стрелкой **`^`**.

Первая цель — личное использование на **Windows 11 x64**. Это отдельная Windows-оболочка вокруг общего Telegram-модуля, локальных правил и необязательного ИИ. Версия macOS остаётся самостоятельной.

## Скачать и запустить

1. Открой Windows-проверку pull request во вкладке **Actions → Windows prototype**. После успешного запуска скачай артефакт **TGFocus-Windows-test-x64** (нужен вход в GitHub).
2. Распакуй артефакт, затем находящийся внутри `TGFocus-Windows-x64.zip`. Перемести всю папку в постоянное место, например `%LOCALAPPDATA%\Programs\TGFocus`.
3. Запусти **`TGFocus.exe`** из распакованной папки. Не запускай из ZIP и не отделяй EXE от `_internal` и `helper` — они содержат Qt, Python и Telegram-модуль.
4. Найди значок в трее и открой настройки. При первом запуске фильтр выключен; автоматизация и ИИ тоже выключены.

Отдельные Python, Qt и инструменты разработчика для готового пакета не нужны. Прототип не имеет платной подписи издателя; Windows SmartScreen может предупредить о неизвестном приложении. Используй только сборку из этого репозитория. Публикация CI-артефакта не является стабильным релизом.

Перед заменой папки новой версией заверши TGFocus через трей. Персональные настройки хранятся отдельно от папки программы.

## Подключить Telegram

1. Получи собственные **API ID** и **API Hash** на https://my.telegram.org/apps . Не отправляй их автору или в issue.
2. Введи их в настройках и подключись. Для QR-входа открой Telegram на телефоне → **Настройки → Устройства → Подключить устройство**. Подтверди вход. При необходимости введи пароль двухэтапной аутентификации.
3. Настрой важных людей, ключевые слова, исключения групп/каналов, упоминания и ответы. Для проверки локальных правил вход в аккаунт не обязателен.
4. Включи главный фильтр. Попроси собеседника прислать подходящее сообщение и проверь настоящий баннер Windows.

Чаты и темы форумов, заглушённые в Telegram, остаются тихими. Приложение не пишет в чаты, не отмечает сообщения прочитанными и не загружает вложения. Уже запущенный обычный Telegram продолжает работать независимо.

## Уведомления и авто-режим

По умолчанию фильтр переключается вручную. Если обычный Telegram тоже показывает баннеры, возможны дубли.

Экспериментальная автоматизация использует официальный **Windows Focus Sessions** API. **Сеанс фокусировки и отдельно включённый «Не беспокоить» — разные состояния.** Переключатель DND сам по себе не считается надёжным сигналом. При неподдерживаемом API или ошибке состояние неизвестно, и доставка TGFocus приостанавливается.

Состояние опрашивается раз в 15 секунд и дополнительно перед доставкой разрешённого баннера, чтобы не показать его по устаревшему состоянию после сна или завершения сеанса. Обработка сообщений в Telegram-модуле меняет режим при следующей проверке; автоматизация не мгновенная. Для немедленной остановки используй главный выключатель.

Чтобы TGFocus показывал важные сообщения во время подавления остальных уведомлений, проверь **Параметры → Система → Уведомления → Задать приоритетные уведомления** и разрешения самого TGFocus. Названия пунктов зависят от версии Windows. API-статус сам по себе не подтверждает, что баннер действительно появился.

Проверь на своём компьютере: обычный режим, включённый сеанс Focus, выключение сеанса, отдельное включение DND и запуск TGFocus при уже активном Focus. Не полагайся на авто-режим для срочной связи до этой проверки.

## Необязательный ИИ

Поддерживаются OpenRouter и DeepSeek. Сначала добавь конфиденциальные диалоги в исключения ИИ, затем укажи провайдера, модель, собственный ключ и порог важности. По умолчанию внешняя обработка выключена. Бесплатность модели/лимиты определяет провайдер; веб-чат DeepSeek и API имеют разные условия.

Внешнему провайдеру отправляются первые 4000 символов подходящего текста, без добавления имён, ID, истории и файлов. Сам текст может содержать личные данные. Исключённые чаты используют локальные правила. При ошибке/лимите действуют обычные ключевые слова; при сбое подключения появляется беззвучное уведомление без повторов на каждое сообщение. Подробности: [AI.ru.md](AI.ru.md).

## Хранение данных

Настройки и секреты находятся в `%LOCALAPPDATA%\TGFocus` (тесты используют изолированный каталог). API-ключи и сессия зашифрованы Windows DPAPI для текущей учётной записи; в обычный JSON правил они не записываются. Код входа и пароль двухэтапной аутентификации не сохраняются. Зашифрованный файл не является переносимой резервной копией для другого пользователя/компьютера.

Журнал решений ограничен и хранится в памяти без текста переписки. Баннеры с разрешённым предпросмотром могут сохраняться самим Windows в центре уведомлений. Во сне и при закрытом приложении обработка не выполняется.

## Сборка из исходников

Нужна **Windows x64 и Python 3.13 x64**. Из корня репозитория:

```powershell
py -3.13 source/Windows/build.py
```

Скрипт создаёт отдельное окружение в `source/Windows/.build`, устанавливает закреплённые зависимости, запускает совместимые тесты, упаковывает оба EXE, проверяет автономный worker и запуск GUI с изолированными данными. Итог — `dist/TGFocus-Windows-x64.zip` и SHA-256 рядом. Сборка Windows EXE на macOS/Linux этим скриптом не поддерживается.

CI не входит в Telegram, не использует реальные API-ключи и не отправляет сообщения провайдерам ИИ. Он проверяет программную интеграцию, сохранение тестовых секретов DPAPI и запуск окон; видимые баннеры, SmartScreen, QR-вход и реальное переключение Focus требуют ручной проверки на Windows.

Пакет включает лицензии компонентов в `Licenses`, в том числе полные LGPLv3/GPLv3 и upstream-уведомления Qt/PySide/Shiboken в `Licenses/Qt-notices`. Используются PySide6 Essentials/Qtbase; необязательные PDF/SVG/WebP/TIFF-плагины не включаются. Python и динамические библиотеки остаются отдельными файлами переносимой папки. `Source` содержит исходники Windows-оболочки, worker и скрипты пересборки. Полные исходники Qt не входят в архив: точные ссылки на upstream-релиз 6.12.0 и инструкция замены совместимых LGPL-библиотек приведены в `Licenses/Qt-notices/README.md`.
