# Telegram Focus

Локальный фильтр уведомлений Telegram для macOS 14+ на Apple Silicon (M1/M2/M3/M4 и новее).

## Запуск

Открой **Telegram Focus.app**. Python и дополнительные библиотеки уже внутри приложения. Начиная с версии 1.3 приложение запускается в фоне без значка в Dock; управление — через значок самолётика в строке меню. Чтобы открыть окно, нажми значок → **«Открыть настройки…»**. Закрытие окна оставляет фильтр работающим; полная остановка — пункт **«Завершить Telegram Focus»** в том же меню.
Перетащи приложение из DMG в «Программы», извлеки образ и запускай установленную копию. Запуск с тома только для чтения блокируется с инструкцией по установке. При запуске второй копии приложение попросит сначала завершить уже работающую версию; окно настроек закрывать недостаточно.

1. **Подключение:** открой ссылку на https://my.telegram.org/apps, войди в свой Telegram и получи API ID и API Hash в API development tools. Для новой записи: App title `Personal Focus` (без слова Telegram), Short name — уникальное имя латиницей, Platform `Desktop`. Если ключи уже есть, используй их, создавать новые не нужно. Введи ключи в приложение и нажми «Подключить». Выбери **«Войти по QR-коду»**: на телефоне Telegram → Настройки → Устройства → Подключить устройство; отсканируй QR и подтверди вход. Пароль двухэтапной аутентификации, если он включён, введи в программе. Альтернатива — вход по номеру и коду. Ключи и коды вводи только в приложение.
2. Нажми **«Тестовое уведомление»** и разреши уведомления macOS.
3. В **«Правилах»** добавь важных людей, слова и при необходимости группы-исключения. Кнопка **«Проверить»** работает без входа в аккаунт.
4. В macOS: **Системные настройки → Уведомления → Telegram Focus** разреши уведомления и баннеры.
5. Выполни настройку ручного режима ниже. Проверь личное со словом «срочно» и обычное сообщение из группы с помощью другого собеседника.

В бесплатной **ad-hoc сборке доступен ручной режим**. Нативные «Фильтры фокусирования» macOS требуют регистрации App Intents с Team ID в подписи. Без него приложение может отображаться в списке фильтров, но кнопка **Add** остаётся неактивной; это не исправляется переустановкой или доступом к уведомлениям.

1. В «Обзоре» нажми **«Перейти в ручной режим»** и подтверди предупреждение. Сохранённая настройка авто-режима до подтверждения держит доставку на паузе.
2. **Системные настройки → Фокусирование → выбранный режим → Приложения → Разрешить уведомления от**: добавь **Telegram Focus**, обычный Telegram оставь заглушённым. В раздел «Фильтры фокусирования» TGFocus добавлять не нужно.
3. Включай главный фильтр TGFocus вместе с фокусированием и выключай его вручную перед выходом из режима. Иначе возможны дубли с обычным Telegram. Если у Telegram включены неотложные уведомления с обходом фокусирования, отключи их.

Заглушённые в Telegram чаты и темы форумов остаются тихими. TGFocus не использует неотложные уведомления и не запрашивает общий статус фокусирования.

В коде сохранена интеграция с `SetFocusFilterIntent` для сборок с Team ID. Его наличие — предварительное условие, а не гарантия регистрации: создание системного фильтра и переключение Focus ещё требуют проверки в корректно подписанной сборке. Поддержка бесплатного авто-режима пока не подтверждена.

Если системный запрос уже отклонён, включи **Системные настройки → Уведомления → Telegram Focus → Допуск уведомлений**, затем повтори тест. Повторное нажатие кнопки не сбрасывает отказ macOS.

## Если код входа не приходит

Версия 1.1 показывает способ доставки, который реально выбрал Telegram: служебный чат, SMS или звонок. Ответ сервера означает, что запрос принят, а не подтверждение получения сообщения. Если код не приходит, выбери **«Код не пришёл — войти по QR»**. QR действует ограниченное время; после истечения можно обновить его вручную. Токен QR не сохраняется на диск и не отправляется сторонним сервисам.

Повторная доставка доступна только если Telegram прислал следующий способ и истёк его таймер. Автоматических повторных запросов нет. Если сервер требует подождать, программа соблюдает полученный срок в текущем сеансе. Вход по электронной почте, Fragment и Firebase SMS в этой версии не реализован — программа сообщает об этом и предлагает QR. В старой версии 1.0 подсказка всегда указывала на Telegram, независимо от фактического ответа: эта ошибка исправлена.

## Правила

- Важные собеседники: все входящие личные сообщения, включая вложения и голосовые.
- Прочие личные: только сообщения с заданными словами/фразами, если не включён переключатель «Все личные».
- Группы и каналы: обычные сообщения заглушены. Исключения задаются по конкретному чату, с требованием ключевых слов или без него. Для семейного чата добавь исключение и выключи «Только с ключевыми словами» — тогда пройдут все сообщения.
- Упоминания и ответы на твои сообщения включаются отдельно. При обновлении старый объединённый переключатель переносится на оба новых: если он был выключен, оба останутся выключенными. Для ответов проверяется исходное сообщение; если оно недоступно, ответ не выдаётся за упоминание. Другие правила чата по-прежнему действуют.
- Если уведомления чата выключены в Telegram, TGFocus не пропустит его даже по ключевым словам, важному собеседнику, упоминанию, ответу или исключению. В форумах сначала проверяется отдельная тема (включая «Общую»), затем родительская группа и общие настройки групп; явное включение уведомлений темы переопределяет наследуемое отключение. Учитываются временное отключение и наследование настроек личных чатов, групп и каналов. При недоступности нужного уровня настроек сообщение подавляется с объяснением в журнале. Обновления настроек сбрасывают кэш; резервный срок обновления кэша — 30 секунд.
- Совпадение по полным словам/фразам: регистр и «ё/е» не важны. `срочно` не совпадает с `несрочно` или `срочного`; нужные формы добавь отдельно. Фразы допускают несколько пробелов и перенос строки.
- Слова проверяются в тексте и подписях к медиа. Распознавания речи, анализа изображений, обработки звонков и секретных чатов нет.
- Список выбора показывает последние 500 диалогов. При необходимости обнови список.
- Нажатие на баннер открывает чат по имени пользователя, доступному номеру или ссылке на сообщение в супергруппе/канале. Если подходящей ссылки нет, открывается сам Telegram.

Закрытое окно не останавливает приложение: оно остаётся в строке меню. «Завершить Telegram Focus» останавливает его. Фильтрация работает при запущенном приложении, бодрствующем Mac и доступе к Telegram. Сообщения старше двух минут после переподключения не вызывают уведомлений. Это защита от лавины старых баннеров, а не очередь отложенных сообщений.

## Данные

Программа подключается напрямую к Telegram через Telethon (MTProto), как отдельная пользовательская сессия. Серверов-посредников, аналитики и внешней нейросети нет. Она не отправляет сообщения, не отмечает их прочитанными, не загружает медиа и не меняет настройки обычного Telegram.

API-ключи и строка сессии сохраняются в **Связке ключей macOS**, пароль и код входа — нет. Сессия даёт доступ к аккаунту: не экспортируй её и не передавай другим. Для отзыва используй «Выйти из аккаунта» в программе или Telegram → Настройки → Устройства → Telegram Focus for Mac → завершить сеанс.

Правила хранятся в `~/Library/Application Support/TelegramFocus/rules.json`: слова и выбранные ID/имена, без ключей и переписки. Журнал последних 50 решений и счётчики существуют только в памяти процесса; текст сообщений в журнал не попадает. Пропущенные сообщения могут сохраняться самим macOS в Центре уведомлений. Отображение текста можно выключить в «Правилах».

## Проверки и ограничения

В поставке есть автоматические тесты правил и обработки входящих событий, входа с кодом/паролем, выхода, отсутствия секретов в ошибках; отдельная проверка упакованного модуля через настоящий канал обмена командами. Живой вход в личный аккаунт и реальная доставка Telegram требуют твоей авторизации и проверяются после подключения.

Сборка подписана локальной ad-hoc подписью. Это локальное приложение, без нотариального заверения Apple. При переносе через интернет на другой Mac система может потребовать обычное разрешение на запуск приложения от неизвестного разработчика; отключать Gatekeeper не нужно.

## Исходники и повторная сборка

Для установки готового приложения используйте DMG из [GitHub Releases](https://github.com/MXLev/tgfocus/releases) и [инструкцию установки](INSTALL.ru.md). Клонирование репозитория и сборка остаются альтернативой; оба варианта требуют Apple Silicon и macOS 14+.

Исходники находятся в `source/`. Для повторной сборки нужны Python 3.13, Xcode Command Line Tools со Swift и интернет для скачивания зависимостей:

```sh
cd "/путь/к/TelegramFocus/source"
python3 build.py
```

Скрипт создаёт локальное окружение в `source/.build`, проверяет тесты, собирает Swift-приложение и автономный модуль Telegram, затем обновляет `.app` рядом с README. Перед обновлением заверши запущенное приложение.

Сборка проверяет, что заменяемое приложение не работает, и использует общую с новым приложением блокировку запуска. Новая копия подготавливается и проверяется до замены старой. Если замена не удалась, сборка пытается вернуть предыдущую версию; при ошибке самого отката сохраняет резервную копию и выводит её путь. Сбор лицензий и подпись выполняются до замены приложения. Это относится к сборке из исходников; при установке DMG заверши старую копию через меню, прежде чем заменять её в «Программах».

Документация: [Telegram API](https://core.telegram.org/api/obtaining_api_id), [Telethon](https://docs.telethon.dev/en/stable/), [уведомления macOS](https://developer.apple.com/documentation/usernotifications).
