# Windows: изменения системы и удаление TGFocus

TGFocus распространяется как переносимая папка. Установщика, системной службы, задания Планировщика, автоматического обновления и исключений антивируса нет. Администратор не требуется. Запись в «Установленные приложения» не создаётся.

## Что создаёт приложение

| Объект | Назначение |
| --- | --- |
| Распакованная папка `TGFocus-Windows-x64` | `TGFocus.exe`, `helper`, `_internal`, лицензии, документация и соответствующие исходники |
| `%LOCALAPPDATA%\TGFocus` | Правила, предпочтения, зашифрованные DPAPI учётные данные и блокировка работающего экземпляра; отдельно от папки программы |
| Пользовательский `shell:Programs\TGFocus.lnk` | Собственный ярлык «Пуск» с идентификатором `MXLev.TGFocus.Windows` для Windows-уведомлений |
| `HKCU\Software\Classes\AppUserModelId\MXLev.TGFocus.Windows` | Значения `DisplayName`, `ShowInSettings`, `IconUri`, регистрирующие отправителя уведомлений |
| Пользовательский `shell:startup\TGFocus.lnk` | Создаётся **только при явном включении автозагрузки**; цель — эта копия программы с аргументом `--autostart` |

`shell:Programs` и `shell:startup` — команды для окна **Win+R**, а не буквальные пути на диске: Windows откроет правильную папку текущего пользователя, включая перенаправленные профили. TGFocus не создаёт ярлыки автозагрузки для всех пользователей. Windows может самостоятельно хранить профиль уведомлений, состояние запрета автозагрузки и записи Центра уведомлений; это не файлы программы.

## Удаление

1. Если больше не нужен доступ к Telegram, пока TGFocus работает выбери выход из аккаунта либо отзови его сеанс в **Telegram → Настройки → Устройства**. Удаление файлов само по себе не отзывает сеанс на сервере. Если больше не нужны API-ключи ИИ, отзови их в личном кабинете OpenRouter/DeepSeek; удаление локального ключа не отзывает его у сервиса.
2. В **Обзор → Запуск вместе с Windows** сними галочку добавления в автозагрузку. Она удаляет только ярлык с собственным идентификатором TGFocus. Если программа уже удалена, открой **Win+R → `shell:startup`**: проверь в свойствах `TGFocus.lnk`, что он ведёт именно к удаляемой копии, и удали только этот ярлык. Чужой одноимённый ярлык не трогай.
3. Выбери **«Завершить TGFocus»** в трее. Закрытие окна настроек только прячет его.
4. Удали выбранную переносимую папку программы. Не удаляй общие каталоги Python, Qt, Programs или LocalAppData.
5. По желанию сохрани `%LOCALAPPDATA%\TGFocus` для переустановки под тем же пользователем Windows либо удали **только эту папку** с локальными правилами и зашифрованными учётными данными. Копии в резервных копиях удаляются отдельно. DPAPI-файл не является переносимым резервным ключом для другой учётной записи.
6. Открой **Win+R → `shell:Programs`**. В свойствах `TGFocus.lnk` проверь цель и удали только собственный ярлык удаляемой копии. Если цель ведёт к другой программе или чужому проекту, оставь его.
7. Необязательная очистка регистрации уведомлений: в редакторе реестра текущего пользователя открой **точно** `HKEY_CURRENT_USER\Software\Classes\AppUserModelId\MXLev.TGFocus.Windows`. Сверь `DisplayName` (`TGFocus`) и `IconUri` с удаляемой папкой программы. Только при совпадении удали созданные приложением значения `DisplayName`, `ShowInSettings`, `IconUri`; пустой ключ можно удалить. Если там есть неизвестные значения/подключи либо принадлежность неясна, сохрани их. Не удаляй родительский `AppUserModelId`.
8. При желании убери уведомления TGFocus через Центр уведомлений Windows. Не удаляй общие ветки `Notifications`, `StartupApproved` и настройки других приложений: Windows управляет ими самостоятельно. Отображение старой записи в параметрах может обновиться не сразу.

Для запуска из исходников ярлык может вести к `pythonw.exe` с путём к `app.py` в аргументах. Проверяй всю команду, а не только имя Python. Общий интерпретатор удалять не нужно.

После переноса программы, вместо удаления/пересоздания системных настроек, запусти нужную копию и используй **«Восстановить регистрацию TGFocus»** и, если автозагрузка включена, **«Обновить путь к этой копии TGFocus»**. Запрет автозагрузки со стороны Windows приложение не снимает.

О данных и внешних сервисах: [PRIVACY.md](PRIVACY.md). О назначении и настройке: [WINDOWS.ru.md](WINDOWS.ru.md).
